# Glim — Implementation Plan

> Built task by task with test-driven development. Each task ends with the gates green
> (`scripts/check.sh`: build, test, strict lint), a build-log entry, and a commit on
> `feature/glim-v1`.

**Goal:** Build Glim as specified in `docs/specs/2026-09-23-design.md`.

**Architecture:** One Swift package. `GlimCore` holds all logic behind protocols and is
unit-tested with fakes. `Glim` (menu-bar app), `GlimWatchdog` (kill-switch helper) and
`Testbed` (practice app) are thin executables bundled into `.app`s by `scripts/build-app.sh`.

**Tech stack:** Swift 6.2 (language mode 6, strict concurrency), SwiftUI + AppKit, Accessibility
API, ScreenCaptureKit, Speech (`SpeechAnalyzer`), AVFoundation, CryptoKit, LocalAuthentication,
Security, Swift Testing. Zero third-party packages.

**Spec:** `docs/specs/2026-09-23-design.md` · **Decisions:** `docs/decisions/2026-09-23-design-questions-and-answers.md`

## Global constraints

- macOS 26.0 minimum; Apple Silicon; Swift language mode 6.
- Apple frameworks only — no third-party Swift packages.
- Names: full descriptive words; no magic literals (named constants with *business rule* /
  *tunable* doc comments).
- No force unwraps, no `try!`, no implicitly unwrapped optionals, no empty `catch`, no `try?`
  that drops an error, no `print`.
- Network: only `127.0.0.1:11434`, `127.0.0.1:8791`, and `api.typesafe.ai` when Jev is enabled.
- Work stays inside this repository.

## Review focus

Inputs the spec implies but could easily be missed; each has a test in the owning task.

1. Typographic variants in labels — "Don’t Save", "Move to Trash…", "SIGN-OUT", non-breaking
   spaces — must still be Forbidden (Task 4).
2. Typed text with a newline, tab or line separator would press Return/Tab (sending a chat
   message) — denied at screening and at the gate; emoji with joiners still allowed (Tasks 7, 8).
3. An impostor app using a trusted bundle identifier with an invalid signature — capped at
   read-only; an impersonated never-touch app stays never-touch (Task 2).
4. Settings file empty, not JSON, edited outside Glim, or sealed with another key — safe
   defaults, reason reported, never a crash (Task 13).
5. Targets or labels with no meaningful words ("the button", empty label) — plan match fails
   closed and asks the person (Task 5).
